# C++ Intermediate Practice

This folder introduces the next topics after variables, operators, conditions and loops.

| File | Topic |
|---|---|
| 01_arrays.cpp | Arrays, sum and average |
| 02_find_min_max.cpp | Minimum and maximum in an array |
| 03_functions.cpp | Functions and return values |
| 04_strings.cpp | Basic string input and length |
| 05_linear_search.cpp | Linear search |
| 06_bubble_sort.cpp | Bubble sort |
| 07_oop_class_object.cpp | Class, object and encapsulation |

## Suggested order
Study one file at a time. First predict the output, then compile, run, change the inputs and explain the logic in your own words.

## Complexity preview
- Linear search: O(n) time in the worst case.
- Bubble sort: O(n^2) time in the average and worst cases; this version can stop early when no swaps occur.

These are learning examples. Practise writing each program without looking at the solution.
