# Coding Practice Checklist

Try each problem independently before checking a solution.

## Fundamentals
- [ ] Read and print two numbers
- [ ] Add, subtract, multiply and divide two numbers
- [ ] Calculate area of a rectangle and circle
- [ ] Calculate simple interest
- [ ] Convert Celsius to Fahrenheit

## Conditions
- [ ] Check positive, negative or zero
- [ ] Check even or odd
- [ ] Find the largest of two numbers
- [ ] Find the largest of three numbers
- [ ] Check voting eligibility using a sample age threshold
- [ ] Build a calculator using switch

## Loops
- [ ] Print numbers from 1 to N
- [ ] Print even numbers from 1 to N
- [ ] Find the sum from 1 to N
- [ ] Print a multiplication table
- [ ] Find the factorial of a number
- [ ] Reverse the digits of an integer
- [ ] Check whether a number is a palindrome

## Problem-solving routine
1. Write the input and expected output.
2. Explain the steps in plain English.
3. Write pseudocode or an algorithm.
4. Convert the logic into C++.
5. Test at least three different inputs.
6. Explain why the condition and loop work.
