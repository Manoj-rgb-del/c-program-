# Beginner Placement Interview Preparation

## Explain a program clearly
Use this structure:
1. What problem does the program solve?
2. What input does it accept?
3. Which variables are used and why?
4. Explain the condition or loop.
5. What output is expected?
6. Which edge cases did you test?

## Common beginner questions
- What is a variable?
- What is the difference between int, float, double and char?
- What is the difference between = and ==?
- What does the modulus operator (%) do?
- What is the difference between if-else and switch?
- What is the difference between for and while loops?
- Why do we use functions?
- What is an array?
- What is a pointer?
- What is object-oriented programming?

## Communication practice
Practise explaining one program aloud in 60-90 seconds. Use simple, accurate English. If you do not know an answer, explain what you understand and say what you would need to learn.

## Important
These notes are a starting point, not a guarantee of placement readiness. Build projects, practise problem solving regularly, revise core computer science subjects, and prepare to discuss your own code honestly.
