# Intermediate C++ Practice Tasks

Attempt these without copying the examples.

## Arrays
- [ ] Find the sum of even elements in an array.
- [ ] Count positive, negative and zero values.
- [ ] Reverse an array.
- [ ] Find the second-largest distinct value.
- [ ] Remove duplicate values from a small array.

## Strings
- [ ] Count vowels and consonants.
- [ ] Reverse a string.
- [ ] Check whether a word is a palindrome.
- [ ] Count words in a sentence.

## Functions
- [ ] Write a function to calculate factorial.
- [ ] Write a function to test whether a number is prime.
- [ ] Create a calculator using separate functions.

## Searching and sorting
- [ ] Implement linear search and report the index.
- [ ] Implement bubble sort in descending order.
- [ ] Compare the number of comparisons for different input sizes.

## OOP
- [ ] Create a Rectangle class with length, breadth and an area method.
- [ ] Create a BankAccount class with deposit and balance display methods.
- [ ] Explain private and public access specifiers.

For every task: write the logic first, code it, test multiple inputs and explain your solution aloud.
